# NetGuard

NetGuard est une application Windows développée en Python
pour surveiller les connexions réseau et analyser l'activité
réseau d'un ordinateur.

## Fonctionnalités prévues

- Surveillance des connexions réseau.
- Affichage des statistiques de trafic.
- Détection de comportements inhabituels.
- Historique des alertes.
- Tableau de bord graphique.

## Technologies

- Python
- psutil
- PySide6
- Matplotlib
- SQLite
- pytest
